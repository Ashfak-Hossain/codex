# Contributing

Thanks for reading! This is a personal blog, so contributions are limited to corrections — not new content.

## What you can contribute

- **Typos and grammar fixes** in any article
- **Broken internal or external links**
- **Math errors** — wrong derivation steps, incorrect formulas
- **Code bugs** — incorrect or non-compiling code samples
- **Broken build** — issues with `quartz.config.ts` or `quartz.layout.ts`

## What to avoid

- New articles or sections — all content is authored by me
- Unsolicited refactoring of the Quartz config or layout
- Changes to the `quartz/` framework source

## How to submit a fix

1. Fork the repository
2. Create a branch: `fix/short-description` (e.g. `fix/gcd-formula-typo`)
3. Make your change
4. Open a pull request with a clear title and a one-line description of what was wrong

For anything larger (e.g. a structural error in a proof), open an **Issue** first using the "Content Error" template so we can discuss before you write a fix.
