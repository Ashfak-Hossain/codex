---
title: DHCP snooping
description: "A switch feature that only lets DHCP server replies in from trusted ports and records who got which address."
tags:
  - glossary
date: 2026-11-23
---

**In plain words:** DHCP snooping makes a switch drop DHCP server messages on untrusted ports, which blocks rogue servers. It also records which IP address was leased to which MAC address on which port, a table that other protections use.

**Think of it like this:** A building's front desk that only accepts address cards from head office, and logs who got which flat.
