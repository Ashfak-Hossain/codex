---
title: DHCP starvation
description: "An attack that uses up every address in a DHCP pool with fake requests."
tags:
  - glossary
date: 2026-11-23
---

**In plain words:** DHCP starvation floods the DHCP server with requests from made-up MAC addresses until the address pool is empty. Real clients then get no address, and a rogue server can step in.

**Think of it like this:** Renting every post-office box under fake names so real customers can't get one.

**Learn it properly in** [[DHCP]].
