**In plain words:** DNS (Domain Name System) turns names like `ashfak.dev` into IP addresses. It's a huge distributed database: your resolver asks a chain of servers, then caches the answer for as long as its TTL allows. It usually runs over UDP port 53. A full page on DNS is planned.

**Think of it like this:** Looking up a friend's street address in a directory before you can write the label.
