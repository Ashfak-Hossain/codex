**In plain words:** HSTS (HTTP Strict Transport Security) is a response header that tells the browser to use only HTTPS for that site for a set time. Browsers also ship a preload list of sites that are HTTPS-only from the very first visit. It's defined in RFC 6797.

**Think of it like this:** A standing instruction: "Never send me postcards, only locked boxes", which the post office remembers.
