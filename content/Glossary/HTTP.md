**In plain words:** HTTP (Hypertext Transfer Protocol) is how browsers and servers talk: the client sends a request with a method, such as `GET`, a path and headers; the server answers with a status code, such as `200`, headers and a body. Its meaning is defined in RFC 9110. A full page on HTTP is planned.

**Think of it like this:** A standard order form and reply slip: "Please send page /notes" and "Here it is (200)" or "No such page (404)".
