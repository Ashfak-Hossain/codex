**In plain words:** An IP address identifies a network interface so packets can reach it. An IPv4 address is 32 bits, written as four numbers from 0 to 255, such as `192.168.1.7`. IPv6 addresses are 128 bits.

**Think of it like this:** The street address on the label. Any post office in the world can use it to work out which way the box should go.
