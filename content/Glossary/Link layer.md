---
title: Link layer
description: "The bottom layer, which moves a frame one hop, to the next machine on the same network."
tags:
  - glossary
date: 2026-11-23
---

**In plain words:** The link layer moves data one hop at a time, from one machine to the next on the same network, over Wi-Fi or Ethernet. It uses MAC addresses.

**Think of it like this:** This is the van that carries the box from one post office to the next. A different van, with a different driver, takes it on the next leg.
