**In plain words:** A network interface is one connection between a machine and a network: a Wi-Fi card, an Ethernet port, or a virtual one such as a VPN tunnel. Each interface has its own MAC address and its own IP address.

**Think of it like this:** One loading door on a building. A big building can have several, each with its own door number.
