---
title: Network layer
description: "The layer that carries packets from one network to another using IP addresses."
tags:
  - glossary
date: 2026-11-23
---

**In plain words:** The network layer carries packets across many networks, from your machine to a server on the other side of the world. It uses IP addresses, and routers make the decisions along the way.

**Think of it like this:** This is the address label on each box. Every post office along the way reads only the label to decide where the box goes next.
