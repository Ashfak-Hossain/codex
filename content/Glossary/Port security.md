---
title: Port security
description: "A switch feature that limits which or how many MAC addresses can use a port."
tags:
  - glossary
date: 2026-11-23
---

**In plain words:** Port security limits a switch port to a set number of MAC addresses, or to specific ones, and blocks or shuts the port if others appear. It makes floods of fake MAC addresses, such as DHCP starvation, much harder.

**Think of it like this:** A door that only opens for the two key cards registered to it.

**Learn it properly in** [[DHCP]].
