**In plain words:** A port is a 16-bit number, from 0 to 65535, that picks which program on a machine receives the data. A web server listens on port 443 for HTTPS; DNS servers listen on port 53.

**Think of it like this:** The flat number in a block of flats. The street address gets the box to the building; the flat number gets it to the right person.
