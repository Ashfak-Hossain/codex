---
title: Rogue DHCP server
description: "An unauthorised DHCP server that hands out wrong settings, such as the attacker as gateway."
tags:
  - glossary
date: 2026-11-23
---

**In plain words:** A rogue DHCP server answers DHCP requests it shouldn't, by mistake or on purpose, handing out wrong settings. An attacker can name themselves as the gateway or DNS server and see the victims' traffic.

**Think of it like this:** A fake information desk in a station, sending travellers to the wrong platform.

**Learn it properly in** [[DHCP]].
