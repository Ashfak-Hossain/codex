---
title: Transport layer
description: "The layer that gets data to the right program on a machine and, with TCP, delivers it complete and in order."
tags:
  - glossary
date: 2026-11-23
---

**In plain words:** The transport layer gets data to the right program on a machine, using port numbers. With TCP it also numbers every byte, resends what gets lost, and hands the bytes over in order.

**Think of it like this:** The locked box is split into numbered boxes, each with a receipt. The receiver can tell if one is missing and ask for it again.
