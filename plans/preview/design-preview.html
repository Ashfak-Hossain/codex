1 · Typography: A, B or C?

The same real text from Layers and Encapsulation in each pairing, with today's fonts last for comparison. Fonts load exactly as Quartz would load them. Use the Light / Dark switch above. Suggestion: A.

2 · Track colours: teal, violet, amber?

Each track gets one accent for its path bar, map line and index heading. Both themes are shown side by side, with each colour's contrast against the page measured live. Suggestion: yes. One catch: these are the same hues as the widgets' layer colours, so teal also means "network layer" inside a widget. Layer colours only appear inside widgets, so I think that's fine, but it's your call.

3 · Mascot Pip: yes or no?

An original parcel with a face and a ribbon bow, in the notebook's post-office world. At most 2–3 appearances per page. Shown with and without, so you can judge the plain callout both ways. Suggestion: yes, but only in plain callouts, the home map and the 404 page.

4 · Home page: keep the terminal hero, or replace it?

Rough layouts only, showing what goes where. The real map comes in P1.4. Suggestion: keep the hero and add the map below, since the terminal is the most personal thing on the site.
